# Heart Attack Prediction - Machine Learning Project

This Machine Learning project aims to predict coronary heart disease (`_MICHD` - Myocardial Infarct / Coronary Heart Disease) using a medical dataset of over 320,000 individuals and 321 features. This work is implemented using **pure NumPy**, without relying on external Machine Learning libraries (in accordance with the project guidelines).

---

## Project Structure

The project directory is organized as follows:

```text
MLProject1/
├── data/                  # Folder containing x_train.csv, y_train.csv, x_test.csv
├── src/                   # Source scripts (preprocessing, models, helpers)
├── results/               # Generated submission files (.csv)
├── requirements.txt       # Project dependencies
└── README.md              # Project documentation

```
